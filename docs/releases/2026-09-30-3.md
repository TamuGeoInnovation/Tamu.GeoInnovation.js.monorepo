## Changed

### The venue notice wording

The notice now reads:

> Due to projected inclement weather in this week's forecast, the Sesquicentennial Opening Ceremony
> will take place in Rudder Auditorium on Friday, Oct. 2. Click here for parking and shuttle route
> details.

It read:

> Because of the forecast, the Sesquicentennial Opening Ceremony on Friday 2 October is now indoors at
> Rudder Auditorium. Click me for parking, shuttles and timings.

<img src="../screenshots/1209-toast-wording/before-prod-wording.png" width="420" alt="The production notice, marked IMPORTANT, reading 'Click me for parking, shuttles and timings'" />

*Before, captured from production while it was live.*

The wording changed twice on 30 September. The first pass
([#1210](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/pull/1210)) replaced
"Click me" and "timings"; the second
([#1214](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/pull/1214)) replaced the
sentence with the text the team settled on, and supersedes it. Both are in this release because the
first never reached production, so there was nothing to undo and no reason to cut a release for each.

The approved text is used verbatim, including "Oct. 2" where the rest of the file says "2 October".

The notice on the event's own map keeps its longer text with the venue, times, parking and shuttles.
The Football and Kickoff at Kyle notices still say "Click me"; making them consistent is separate and
does not justify a release today.

## Behind the scenes

- **These were the first changes verified with affected builds before pushing**, following the rule
  added in [#1200](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/pull/1200) —
  rather than after a check caught something. The first run covered 7 projects with
  `correction-lite-angular` holding at 1021.19 kB against its 1024 kB budget; the second covered 7
  projects in 17 minutes, lint, test and build all clean.

  The difference between the two is the point of the rule: a string in a library rebuilds seven
  projects, where the same edit inside an application rebuilds two. Picking one app by hand would
  have checked neither set.
- **The second release's notes linked a screenshot that was never committed.** `after-dev-grouped.png`
  is supplied by [#1208](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/pull/1208),
  which is still open, so that image is broken on `development` until it merges. Worth knowing because
  it is the failure the notes rule exists to prevent
  ([#1132](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1132)), and it
  happened anyway — the notes and the image were in separate pull requests.
