# AggieMap release — 25 September 2026

**Status: shipped to production on 25 September 2026.** Everything below is live on
`aggiemap.tamu.edu` and on `dev.aggiemap.tamu.edu`.

## Summary

- **Five 150th anniversary event maps**, two of them new. Kickoff at Kyle is public and its
  toast started on 25 September; the 150th Opening Ceremony map for the same day remains
  hidden pending announcement.
- **Three satellite-campus maps** — Galveston, McAllen and DC / Bush School. Reachable in
  production by direct link, deliberately not listed or searchable there.
- **Construction layers** now read from Transportation Services' hosted service, which fixes
  the construction event map that previously drew nothing.
- **Construction popup dates** now render as dates rather than raw numbers.
- **Dining** gains a kiosk-style map for embedding, plus a popup status fix.
- **Directions To Here** is removed from the two new event maps while routing is rewritten.

### Three senses of "hidden"

- **Reachable** — the URL works for anyone who has it. Every map above is reachable.
- **Discoverable** — the map appears in the All Maps search, the Upcoming Events list and the
  campus groupings. This is what the visible flag controls.
- **Announced** — a toast appears on the main map in the seven days before the event.

A map can be reachable but not discoverable. That is deliberate for events not yet announced:
a direct link can be shared without the public stumbling onto it.

### Kickoff at Kyle and the Opening Ceremony

Two maps cover 2 October with opposite settings. The **150th Opening Ceremony** map is
deliberately hidden until the event is announced. **Kickoff at Kyle** shipped discoverable,
and its toast began on 25 September — so an embargoed event now has a publicly discoverable
parking map for the same day.

It is also more prominent than "discoverable" suggests: Kickoff at Kyle took a slot in
**Upcoming Events on the front page**, displacing Football.

This shipped as described rather than being settled. Hiding it is a one-line change if the
embargo should cover both.

**How the gating works.** The Campus Maps tile and section appear only when the hostname
contains `dev` or `localhost`. Satellite-campus maps are excluded from the map search in
*both* environments. So on `aggiemap.tamu.edu` there is no route in unless you already know
the URL. This is the intent: live as unadvertised links for the testing team, without being
announced. The dev-only section lists all three with copyable URLs for that purpose.

## Construction

All construction layers now read from one Transportation Services hosted feature service,
`Hosted/TSConstruction_Hosted/FeatureServer` on `arc.ts.tamu.edu`, replacing two older
services. The old `TS_Events/TSConstruction/MapServer` returned attributes but no shapes,
which is why the construction event map drew nothing.

The `arc.ts.tamu.edu` host is pinned to production even on dev, so both environments read the
same construction data.

Alongside it:

- **Popups read the construction fields case-insensitively.** The new service uses lowercase
  names (`name`, `startdate`); the old ones used PascalCase. One popup now serves both.
- **Symbology** comes from the hosted service's own cross-hatch renderer. Maps needing one
  uniform construction style instead of the service's per-owner colours set a single orange
  cross-hatch renderer.
- **Other apps** received the same URL change in their definitions — trees, GIS Day
  competitions, football, move-in/out, Ring Day and the four UES apps. Each picks it up when
  next built and deployed.

### Construction popup dates

Start Date and End Date on the Construction Map showed raw epoch milliseconds
(`1754784000000`) instead of dates. Reported by Megan during testing.

The fields are genuine date fields and the service was behaving correctly — ArcGIS returns
dates as epoch milliseconds. The Construction Map builds its popup by substituting values
into a template string, which had no way to format a value, so the number was printed
verbatim. Popup fields can now declare a date format.

The main AggieMap construction popup was never affected; it formats dates in its component
template.

## Also in this release

**Directions To Here** is removed from the two new event maps. The routing service behind it
is unpublished and being rewritten, so the button could not work. The share and copy link in
the popup is unaffected. Removing it from the rest of the site is tracked separately.

## Known data issue

The two new feature services carry event dates already in the past, left over from whatever
they were cloned from:

| Service | Dates in the data | Actual event |
| --- | --- | --- |
| `Live_at_the_Station` | 28 Feb – 1 Mar 2026 | 7 Nov 2026 |
| `Kickoff_at_Kyle` | 10–18 Apr 2026 | 2 Oct 2026 |

This does **not** affect the maps — the dates driving the site come from the map definitions,
which are correct. But anyone reading the service data directly will be misled, and the
pattern will repeat on the next cloned service.
