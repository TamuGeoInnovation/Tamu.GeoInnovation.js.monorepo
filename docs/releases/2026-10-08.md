# 8 October 2026

**This release went to production before its dev check, as an emergency.** During Ring Day, the main map
showed two notices about it ([#1570](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1570)), and the fix ([#1571](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/pull/1571)) could only
reach production with everything else merged since 6 October. Azure Release-459 deployed build
20261008.11 (`9105eff8`) to dev at 1:56 PM Central and to production at 1:57 PM, with no suite run between.

**Checking production afterwards found two regressions**, both from the second 6 October release rather
than from this one: Dining and AggiePrint drew as plain dots ([#1576](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1576)), and zooming all
the way in turned the map white ([#1577](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1577)). Both were fixed the same afternoon
([#1579](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/pull/1579), [#1580](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/pull/1580)) and deployed on top: Release-460, build 20261008.15
from `a4e04a7b`, to dev at 4:01 PM and production at 4:02 PM Central. That is the build these notes describe,
and the one tagged.

**The suite cleared it on production**: 397 passed, 0 failed, 0 flaky, 24 skipped
of 421, in 19 minutes 39 seconds (4:07:46 PM to 4:27:25 PM Central, release scope, 6 workers). Every map loaded and drew, including the campus and All Maps notification tests that failed on production that morning while the hard-coded Ring Day notice was showing. The two new checks pass on production too: the basemap at the deepest zoom, and the Dining and AggiePrint icons (checked by eye, with both layers on).

The production stage started by itself a minute after dev both times. That was wanted today; as a habit it
lets an unchecked build reach production, so [#1584](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1584) puts an approval gate on it.

Most of the release is invisible: **every Angular app now starts as a standalone application**, with no
`AppModule` and standalone components throughout ([#1452](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1452)). It was checked locally
against production's services before merging (428 passed) and walked app by app in a browser.

## Summary

- **Dining and AggiePrint locations have their icons back** ([#1576](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1576)). Since the second 6 October
  release they drew as plain dots: that release took the symbology from each layer's service, and
  these two sources publish none worth drawing (Dining is a GeoJSON feed; AggiePrint's service publishes
  ArcGIS's default marker). Their own icons are restored, and a test now fails if they go again.
  ([before](../screenshots/dining-aggieprint-icons/before.png), [after](../screenshots/dining-aggieprint-icons/after.png))
- **Zooming all the way in no longer turns the map white** ([#1577](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1577)). The campus basemap has tiles
  down to 1:282, but the maps let you zoom two levels further, where there was nothing to draw. Every
  map now stops at the deepest level the basemap has. ([before](../screenshots/basemap-max-zoom/before.png),
  [after](../screenshots/basemap-max-zoom/after.png))
- **Ring Day shows one notification, not two** ([#1570](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1570)). During October 2026's Ring Day the
  main map stacked two notices about it ("1 of 2"): an old hard-coded one, and the one the Ring Day
  event map raises itself. The hard-coded one is gone, and a test now fails if any hard-coded notice
  runs while an event's own notice is showing. ([before](../screenshots/ring-day-one-notification/before.png),
  [after](../screenshots/ring-day-one-notification/after.png))
- Not visible: **standalone components** ([#1452](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1452)). The UI kits, common, map, AggieMap,
  event-map, GIS Day, geoservices, mailroom and UES libraries; every app bootstrapped with
  `bootstrapApplication`; and the 53 NgModules that only re-exported components removed. Ring Day's old
  standalone app, the OIDC admin and signage apps are left out. The routing modules remain ([#1569](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1569)).
- Not visible: the CPA projects retired ([#1458](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1458)); GitHub and Azure pinned to Ubuntu
  24.04 before the 19 October image change ([#1407](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1407), [#1468](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1468)); the
  tsconfigs moved off options TypeScript 6 deprecates ([#1476](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1476)); the apps start on a local
  dev server again ([#1558](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1558)); the smoke suite typechecked on every pull request and its bus
  test split per route ([#1470](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1470), [#1473](https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo/issues/1473)).
