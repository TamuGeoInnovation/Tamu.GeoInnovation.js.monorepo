## Item 1: #1426, a faster release check

**Branch: `cloud/1426-smoke-speed`**, from `development` at `4d7f1d7`. Four commits; `.pr-body.md` is the
last one. Pushed, ready.

What it does, as decided:

- **One framing route per map for a release check.** Set by `AGGIEMAP_SMOKE_FRAMING=release`, which
  `run-local.sh` sets unless told otherwise. The workflow sets `full`, so the daily run still opens all
  421. A baseline refresh is always full. On dev that is **70 routes, not about 52**: dev lists 70 maps
  (there are more maps now than when 52 was counted).
- **The ArcGIS SDK, cached per worker** (`test/smoke/aggiemap/fixtures.ts`). A fresh context per test as
  before, with `js.arcgis.com` served from memory through `context.route`. 20 specs now import `test`
  from `./fixtures`. Checked by counting: on a worker's 2nd and 3rd map, 85 of 87 and 86 of 90 SDK
  requests came from the cache.
- **Polling instead of 1000 ms sleeps.** The probe-ready wait polls every 250 ms. The framing settles
  once it has been unchanged for 1 s, read every 250 ms (it was three readings 1 s apart).
- **6 workers locally**, 4 on CI.

  20 min. Framing is now about 12 min of test time. What remains is maps (71 tests, about 50 min), event
  dates (13 min) and the bus test below.
