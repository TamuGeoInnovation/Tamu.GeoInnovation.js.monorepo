## What this changes

Two tests in `libs/maps/feature/basemap/src/lib/shared/basemaps.definition.spec.ts` scan every `.ts` file under `libs/` and `apps/`:
- "is used only by views that let the basemap decide the spatial reference"
- "is never named outside its definition, so every map resolves it by environment"

Each called `sources()`, which walked the whole tree, and then read every one of its 1,400 or so files from disk. The first test carried the cold walk and overran Vitest's 5-second limit whenever the machine was busy: 9.5 s and 5.9 s in two full checks on 23 November. A full check then had to be run twice, and a real failure in this project would have looked like the same noise.

- **`sources()` walks and reads once per spec file**, caching each file's text, and the tests filter that list in memory.
- **The `campus basemap` describe's `beforeAll` does the scan, with its own 180 s**, and a comment saying why. The tests then time their assertions rather than the disk.
- **Every assertion is unchanged.**
