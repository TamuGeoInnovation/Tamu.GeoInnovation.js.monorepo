## What changed

`scripts/check-strict-libs.mjs`, with the maintainer's three rules:

1. **Own errors only.** `ownErrors(out, root)` counts an error when its file's nearest project root is the library, plus file-less errors.
   - **By project root, not path prefix**, because `ui-kits-ngx-layout` contains two projects of its own (`-code`, `-modal`): a prefix match gave
     it `layout-code`'s 2 errors.
   - That was found by its test, red, before the fix.
2. **Count beside the library:** `<project root>/strict-errors-known.txt`, one number with `#` comments; no file means zero.
   `scripts/strict-lib-errors-known.txt` is deleted. Nothing else named it (not CLAUDE.md, not the docs), only the script and its test.
3. **Only a rise fails.** A lower count prints `notice: … can come down to N`, and a clean one `notice: … can be deleted`.

**New:** `--all --write`, which re-measures every strict library and writes or deletes each file.
