## Q-a34-1 first: yes, the map search works on a local build here

On a local **production-configuration** build of `aggiemap-angular` at `development` (`77a7b8051`), served with CLAUDE.md's dev-server command plus
`--configuration production`, typing **`Evans`** into "Find Building or Parking" on `/map/d` lists:
- Evans Library (0468.1);
- Evans Library Annex (0468.3);
- Sterling C. Evans Library (0468).

The console showed no errors, and the search's own queries all answered 200. #3477's branch does the same.

**The most likely difference from your setup is how the text is typed, not the environment.** The search box searches on **`keyup`**
(`(keyup)="change($event)"` in `search.component.html`). Playwright's `fill()` sets the value without any key events, so the box holds the text, the
results container stays empty and nothing is queried, which is exactly what you saw. I typed key by key (`pressSequentially`, 80 ms a key).

If your run used `fill()`, that is the whole of it. If it typed key by key, the next thing to compare is the GIS servers: the queries go to
`arc.ts.tamu.edu`, `gis.it.tamu.edu`, `gis.tamu.edu` and `services1.arcgis.com`, and all answered here. Nothing about the environment file or
`SearchSources` differed: I used the repository's own.
