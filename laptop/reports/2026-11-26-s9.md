## 4. `@vaadin/vaadin-usage-statistics` (row 6)

- **What pulls it in:** `@arcgis/core` → `@vaadin/grid` → `@vaadin/component-base`, so it is a production dependency of every map app.
- **The refused install script is the one that would install its opt-out file,** so the collecting code is what `element-mixin.js` imports.
- **It runs only through `runIfDevelopmentMode`, on `localhost` or `127.0.0.1`**, from a `vaadin-dev-mode` comment block that only an
  unminified build runs. So it sends **nothing from a production host**.
- **A developer's dev server could** post to `tools.vaadin.com` monthly, if a Vaadin element is created.
- **Evidence:** `aggiemap.tamu.edu/map/d` loads 242 scripts (2.9 MB) with none of the statistics code, and `window.Vaadin` undefined.
- **Dismiss.** Optionally, document `localStorage.setItem('vaadin.statistics.optout', '1')` for developers.
