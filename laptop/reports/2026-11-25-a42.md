## How

- **The diffs:** `gh pr diff <n>` for each, **cached** in `laptop-tools/a42/diffs/<n>.diff` with the list in `prs.json`, so the analysis
  (`laptop-tools/a42/overlap.mjs`, output in `overlap.json`) re-runs without fetching.
- **Compared per shared file, by hunk ranges:**
  - **same lines:** the changed ranges overlap;
  - **adjacent:** within 3 lines, which git also treats as touching;
  - **apart:** further than that;
  - also **both add it**, for the same new file in two pull requests.
- **Caveat:** each diff is against that pull request's own merge base. Where two branches started from different `development` commits, line numbers
  can be off by a few. **Treat "adjacent" as a warning, and "apart" as safe**; for a cluster that matters, the lab's real merge is the proof.
