## 2. The change

- **One shared piece: `PhotoCarouselComponent`** (`<tamu-gisc-photo-carousel [photos]="…">`) in **`libs/ui-kits/ngx/layout`**, exported from
  its index.
  - **Why there:** CLAUDE.md sends anyone looking for a component to `libs/ui-kits/ngx/**`, and a carousel of photos that opens full
    screen is not specific to AggieMap. `layout` already holds the general-purpose components (accordion, tabs, drawer, stepper, tooltip).
  - **What it does:**
    - **the Swiper carousel exactly as before** (same options: one slide per view, loop, arrows);
    - each slide is a link to its photo, and **a click opens that photo in GLightbox** (`openAt(index)`) instead of following the link;
    - in the full-screen view, **arrow keys and swipes move between photos and Escape closes it** (GLightbox's own keyboard and touch
      handling);
    - the GLightbox instance is destroyed with the component.
  - **Spec** (Vitest, 3 tests): one full-screen element per photo, in order; a click opens that photo and cancels the link; the instance is
    destroyed with the component.
- **Both popups now use it.** The POI and bonfire popups lose ~40 lines each: the Swiper set-up, the lightGallery init, and **a refresh hook
  that was never wired up** (`onLightGalleryInit` was bound to nothing, so `_needsRefresh` was never true), plus an unused `settings`.
- **`glightbox` 3.3.1 (MIT) in place of `lightgallery` 2.9.0.** The lock change is exactly those two, nothing else.
- **Cleaned away with it:**
  - `jest.preset.js`'s module mapping for lightGallery's nested Angular module (`lightgallery/angular/13`), which nothing imports;
  - `|lightgallery` from the `transformIgnorePatterns` of **19 Jest configs**;
  - lightGallery's stylesheet from AggieMap's and ts-events' `styles.scss`.
  - The release notes and the build-times history that mention it are history and stay as written. So does one comment in the smoke suite's
    global setup, which explains a past decision.

**One departure from the batch, with its reason: GLightbox's stylesheet is global, not imported by the shared component.** That was my first
version: the component imported it, unscoped. But the check failed: **`ts-events-angular`**, which shows AggieMap's popups, enforces a **10 kB
component style budget**, and GLightbox's stylesheet is **13.6 kB** (*"exceeded maximum budget"*). The full-screen view is also built at the
end of `<body>`, outside any component, so it is a globally-applied widget, which CLAUDE.md puts in an app's `styles.scss`. So it is
`@import 'glightbox/dist/css/glightbox.min'` in the `styles.scss` of **the three apps that can show these popups**: AggieMap and ts-events,
where lightGallery's was, and `ues-operations-angular`, which uses the same definitions and never had lightGallery's stylesheet. The
component's own documentation says so. **This matches what batch 84 found for MapLibre.**
