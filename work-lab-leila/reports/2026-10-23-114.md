## 2. What changed between 12 and 13 that touches us

From its release notes:
- **13.0.0 moved to N-API** and **publishes its prebuilt binaries inside the package**, dropping the deprecated `prebuild-install`. Today's 12
  downloads its binary in an install script; **13 has no install script at all.** Its lock entry has no `hasInstallScript`, and its
  `package.json` has no `install`/`postinstall`, only `build-release` and the like. The binaries for each platform are in `prebuilds/`, and it
  needs Node `>=22`.
- **13.0.1 to 13.0.3:**
  - parameter binding accepts plain objects from other realms again (Jest);
  - terminating worker threads no longer aborts the process;
  - table parameters are validated;
  - **SQLite moves 3.53.2 → 3.53.4**;
  - an arm64 build change.
- **For us:** none of it changes the API anything here calls. The one direct user is `ues-operations-nest`'s session store, which CI excludes,
  as before.
- **For #2293 / PR 2317:** 13 runs no install script, so **its `allowScripts` entry becomes stale** once both merge. `install-scripts.mjs` then
  reports it as *Not installed any more, so these entries can go* (not a failure), and `npm install-scripts prune` removes it.
