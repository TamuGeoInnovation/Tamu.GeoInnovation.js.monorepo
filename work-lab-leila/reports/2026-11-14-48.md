## What changed

- **The photo:** the small circle is gone. The page uses `tamu-gisc-image-preview` (fallback `person`), in the same
  17rem box as the admin form. It shows the photo just chosen, else the current one, else the person icon.
- **The banner:** `tamu-gisc-speaker-class-banner`, drawn only while a photo is showing (as #2568 has it).
  - It reads a `bannerSpeaker` signal, built from the form's changes and the season's universities.
  - The universities list is now shared (`shareReplay(1)`), so it isn't fetched twice.
- **Shared, not copied.** Two pieces the admin form kept to itself are now shared, and the admin form's own interface
  is unchanged:
  - **`classBannerSpeaker()`** in `utils/speakers.ts` replaces the admin form's inline mapping from university and year
    to what the banner shows. Both pages call it.
  - **A `class-banner-photo` mixin** in `libs/gisday/sass/_class-banner.scss` holds the admin form's photo box,
    unchanged. Both pages include it.
  - **`_class-banner.scss` now loads its own variables and mixins under a namespace,** so a stylesheet can `@use` it as
    well as `@import` it. A first version without the namespace broke the build ("both define a variable named
    `$accent-grey`"), and this one builds.
