## The shared check

- **One check, not copies:** `refuseUnsafeImage(file, label)` in
  `libs/gisday/platform/data-api/src/lib/assets/image-upload.ts`. The old `_refuseUnsafeImage` and `refuseUnsafePhoto`
  are gone, and so is the `isPng` naming in `SpeakerEditService.approve`.
- **Judged by content:** it reads the file's header with the existing `readImageSize` from
  `@tamu-gisc/common/node/images`.
  - Anything that isn't a JPEG or PNG gets a **400**, for example "The logo must be a JPEG or PNG image."
  - So does a file with no content. Before, a speaker photo without one skipped the check.
- **Pixel size:** a header declaring more than 8000 px a side, or 40 megapixels, gets a **413**. Speaker photos already
  had this, and logos now do too.
- **The stored name follows the content:** a PNG named `logo.svg` is stored as `logo.png`.
- **The 5 MB limit is unchanged.** It is still `DEFAULT_UPLOAD_LIMITS.fileSize` on every upload interceptor, which runs
  before the check.
- **The forms:** the admin forms for speakers, sponsors, organizations and places changed from `accept="image/*"` to
  `accept="image/jpeg,image/png"`.
- **The test fixture** is a bare `<svg xmlns="http://www.w3.org/2000/svg"/>`, with no script. No working malicious file
  is anywhere in the branch.

**Where I looked for something to reuse:**
