## 1. The mirror, and who may write it

- **A bare mirror** of `https://github.com/TamuGeoInnovation/Tamu.GeoInnovation.js.monorepo.git` in the Docker **volume**
  `tamu-agent-git-mirror` (not a host folder): `git clone --mirror`, **512 MB** with every branch, tag and the 1,195 pull-request refs GitHub
  publishes.
- **Written only by the supervisor, only from `origin`.** `Confirm-Mirror` (and `confirm_mirror` on Linux) runs before every job. It clones
  the first time and `git fetch --prune`s after that, **in a short container of its own** (the agent image, entrypoint `flock`) on Docker's
  default network. **Never in a job's container.** A **lock** (`flock /mirror/.lock`) keeps agents started together from fetching into it
  at once. **If the refresh fails, it warns and carries on**: the job still checks out, fetching more from GitHub.
- **Mounted into each agent read-only:** `--mount type=volume,source=tamu-agent-git-mirror,target=/mirror,readonly`.
- **Why a fork job cannot change it:**
  - the mount is read-only: `touch /mirror/probe` gives *Read-only file system*;
  - its files are root's;
  - the only writer is the supervisor, fetching from GitHub.

  So a fork's pull request can read it (it is the public repository) but cannot plant an object a later job would borrow.

## 2. The checkout

**The checkout task cannot take a reference repository**, so the lab twins of the heavy jobs use **`checkout: none` plus a script**
(`templates/tasks/checkoutFromMirror.yml`). The hosted twins keep the checkout task. The script:

1. `git init` in `$(Build.SourcesDirectory)`;
2. if `/mirror/monorepo.git` exists, write its `objects` path to **`.git/objects/info/alternates`**, so git borrows the mirror's objects instead
   of downloading them;
3. **fetch from GitHub**, `origin` = `$(Build.Repository.Uri)`: every branch (`+refs/heads/*:refs/remotes/origin/*`) and, for a pull request,
   `+refs/pull/<n>/merge`. **The refs come from GitHub, not the mirror**, so the commit checked out is the one GitHub names;
4. `git checkout --force $(Build.SourceVersion)` (the same commit the checkout task uses), and print the commit and its tree.

**`fetchDepth: 0` behaviour is kept**: nothing is shallow. Without a mirror the step fetches everything, with a warning, exactly as the
checkout task would.
