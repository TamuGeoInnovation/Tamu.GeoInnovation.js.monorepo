**Four bugs, found by these runs and fixed before the commit:**

- **`2>&1` under `$ErrorActionPreference = 'Stop'`**: Windows PowerShell made the agent's first stderr line a terminating error, which ended
  the wrapper silently mid-run. The wrapper now uses `Continue` around that one call.
- **The installer killed itself**: its stop-old-processes filter matched its own command line. It now matches only the `bin` copies and
  never `$PID`.
- **`0x8007010B`** from the task's working directory. It is now dropped, and `conhost.exe` is given its full path.
- **The `\t` in my own edits** became tab characters in two paths (the same fault as in the batch's own text). Fixed, and every file scanned
  for control characters.

**A test artefact worth knowing:** this session's tools write `%LOCALAPPDATA%` into a sandbox overlay that a real scheduled task cannot see, so
the first runs failed on *file does not exist*. The tests then used `LOCALAPPDATA=C:\TAMU\b15\lad` while installing. **On the maintainer's own
logon this does not arise.** The task's own log went to the real `%LOCALAPPDATA%\tamu-build-agent\logs\`, where three `agent-lab-test-*.log`
from these tests remain (no token in them).
