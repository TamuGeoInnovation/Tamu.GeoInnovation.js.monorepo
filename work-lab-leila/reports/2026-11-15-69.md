## How "as gisday.tamu.edu" reached the API

**The problem:** locally the page and the API share one origin. So a GET carries no `Origin` header, and nginx sets `Host`
to `localhost`. Left like that, the branch's API would treat the page as txgisday.org and return all 114 events.

**What the capture did:** it added `x-forwarded-host: gisday.tamu.edu` to every API request, which `siteHost()` reads.

**Production should be fine:** gisday.tamu.edu calls the API from another origin, so it sends `Origin`.
