## What I built, and why it is one list rather than a comparison

**A check that compares two templates still lets them differ until it runs.** So I removed the second list instead.
`AGGIEMAP_SIDEBAR_TABS` in `libs/aggiemap/ngx/ui/desktop` holds every tab: id, title, description, icon, route, and a
`developmentOnly` reason where there is one. Both sidebars loop over it.

- **The main map's sidebar** draws every tab and hides the development-only ones off a development host, as before.
- **The event, parking and campus maps' sidebar** draws the same list, less any tab its `sidebarTabs` leaves out.
- **Directions keeps its one gate**, in the list: when #2804 removes it there, Directions is on every map at once.
- **Experiments came along**, because it is in the main map's list. It is development-only, so production does not see
  it. The list gives its reason as "development-only since it was added, with no reason recorded", which is the truth.
  Say if you would rather event maps not have it.
- **The satellite campuses** keep Features alone through `sidebarTabs: ['features']`, unchanged.

**And then a comparison anyway, as the check across maps:** a unit spec renders both sidebars and requires the event one
to offer exactly the main one's tabs, as development and as production. A second list or a hand-written tab fails it.

## What the tabs needed, found by using them

1. **Event maps had no `bus` or `experiments` route.** Added beside `trip` and `settings`.
2. **The bus panel listed routes but drew none on an event map.** Choosing route 01 threw `TypeError: Cannot read
   properties of null (reading 'graphics')` in `BusService.toggleMapRoute`.
   - **The cause:** `BusService` is `providedIn: 'root'` and waits on `EsriMapService.store`. An event map provides its
     own `EsriMapService` (`map.component.ts`), so the root one's store never emits there, and the bus layer is never
     made.
   - **The fix:** event maps provide `BusService` too, as they already do `TripPlannerService` for the same reason.
   - **It is a latent bug** that no visitor could reach until the tab existed, and `bus.spec.ts`'s route 01 test now runs
     on an event map as well, so it cannot come back unseen.
