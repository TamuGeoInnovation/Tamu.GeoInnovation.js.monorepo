## The service worker is registered, so this uses it

- **Registered in both deployed builds:** `apps/gisday-angular/src/main.ts` registers `ngsw-worker.js` whenever the
  environment's `production` flag is true. It is true in both deployed builds (`production` and `development`), and
  both build with `ngsw-config.json`.
- **Never served from a cache:** txgisday.org serves `ngsw.json` with `no-store, no-cache, must-revalidate`, through
  the existing nginx rule.
- **Every deploy counts as a new version.** `assetGroups` is empty, so the worker caches none of the app's files. But
  each build's `ngsw.json` carries its own timestamp.
- **So no new version file was added.** It uses Angular's `SwUpdate`, as the issue suggests, and needs no server or
  build change.

**When it checks:** after each navigation (at most every 30 seconds), and when the tab becomes visible again. The page
asks the worker (`SwUpdate.checkForUpdate()`), and the worker fetches `ngsw.json` with a cache-busting parameter.

## The three behaviours

- **A newer version, nothing unsaved:** when the worker reports a newer version, or that it can no longer serve this
  one, the page reloads at its current address.
- **A newer version, with unsaved changes:** it never reloads on its own. It shows the existing `AlertModalComponent`
  once: **"A newer version of this site is ready"**, with **Keep working** and **Reload now**.
  - After Keep working, the next page opened with nothing unsaved loads from the new build.
  - **"Unsaved" means a `form.ng-dirty` on the page.** That's a default an application can replace.
  - It errs on the safe side: a saved form that wasn't marked pristine gets the question, not a reload.
- **A missing chunk:** one reload, at the address the visitor clicked.
  - The time is kept in `sessionStorage`, and another missing chunk within 2 minutes is only logged. So it can't loop.
  - If session storage refuses the write, it doesn't reload at all.

**Where the code is:** `libs/common/ngx/router/src/lib/new-version/` (`chunk-load-error.ts`,
`new-version.service.ts`, two tokens and `provideNewVersionReload()`), exported from the library's index. Any app can
use it. `gisday-angular`'s `main.ts` adds `provideNewVersionReload()`, and that is its only app change.
