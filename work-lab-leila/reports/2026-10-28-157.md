## Verdict on PR 2519

**The check works, so merge it, but not as the whole answer.** Three things:

1. **Graduation will turn the release tier red** on both environments, from the night it merges: Fall and Spring, Road Closures.
   That's a real finding, but it needs its own issue and either a fix or an entry in `environments.json`'s known failures before
   this merges. Otherwise it becomes the next always-red test.
2. **On production it does nothing until #1134 is done.** The relabelled run shows the simplest option works:
   - accept the dev inventory on production;
   - treat a destination that doesn't land as a skip with a note, not a failure;
   - say in the log which inventory was used.

   That's a small change in `builder-destinations.ts`, and it's what would have caught #2500 on the night it went live.
3. **Baseball's event mode is never loaded**, because the inventory records one layer set for both modes. A destination per
   option value, at least for maps whose options change the layers (baseball's `map-mode`), would close that.

**Recommended order:** file Graduation's issue and add its known-failure entry in this PR, then merge. Then #1134's option 1 as the
next pull request, proven on production against this same baseball fault, if it's still live.
