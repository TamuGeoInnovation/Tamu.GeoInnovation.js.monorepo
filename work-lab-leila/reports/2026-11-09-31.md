## Where it is read from, and why

1. **The connection:** `micromobilityUrl` is named on `gis.dev.tamu.edu` outright, as `ncaaVolleyballUrl` is, and
   **read from that server on every environment, localhost included.**
2. **It leaves `READ_FROM_PRODUCTION_ON_DEVELOPMENT`.** That entry said the development copy answered 499 Token
   Required; the new service is public there. So the Layers list's "production data" mark is gone (visible in the
   before/after).
3. **Still development-only.** `developmentOnly` keeps the map off production, and `DEVELOPMENT_ONLY_LAYER_SOURCES`
   keeps the main map's group out of a production build. A development-only source for a development-only map is
   coherent, and the comment says so. **Moving the map to production means naming production's copy of this service**,
   which Transportation has not published.
4. **The smoke entry moved with it.** `DEVELOPMENT_ONLY_SERVICES` now names `Hosted/Approved_Micromobility_Paths_view`,
   with the same pages (`/transportation/micromobility`, `/map`). The old key would have watched a service nothing
   requests.
