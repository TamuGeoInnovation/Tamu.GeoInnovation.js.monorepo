## The change

- **`uncovered(allowScripts, packages, installed)`** takes, third, the names of every package the lock installs (`installedNames(lock)`, new
  and exported). It returns:
  - **`unused`**: entries whose package is **not in the lock at all**, reported as *Not installed any more, so these entries can go (npm
    install-scripts prune)*;
  - **`noScript`** (new): entries for a package the lock **installs without `hasInstallScript`**, reported on their own line, *Installed, but
    no install script recorded in the lock; npm may still treat a binding.gyp as one, so these stay*.
- **Neither fails the check, as before.** Without the third argument the function behaves as it did, every unmatched entry `unused`.
- **The README's description** says which is which, and why `better-sqlite3` 13's entry stays.
