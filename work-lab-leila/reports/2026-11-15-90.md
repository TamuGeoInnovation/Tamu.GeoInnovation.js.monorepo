## The Profile email: a copy each only (question 1)

**It gets the tick boxes, but is only ever sent as a copy each.**
- **Why:** each copy carries **that speaker's own edit link**, and anyone holding it can edit that profile. So one email to
  several speakers would let each edit the others' profiles.
- **In the composer:** that reason is shown where the choice would be.
- **In the client:** it never sends `together` for it.
- **In the API:** `speaker-edits/send` and `send-for-submissions` refuse `together` with a 400, before anything is sent.
