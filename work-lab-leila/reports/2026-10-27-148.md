## 1. #2487: does the basemap draw, and what stops it

### How I looked

- **Headless Chromium** in `mcr.microsoft.com/playwright:v1.64.1-noble`, with WebGL on SwiftShader, 1280 x 900, `America/Chicago`.
- **Not the browser pane.** It was hidden, so its page ran in the background, where a WebGL canvas may never paint. That alone
  could explain an empty map, so nothing below comes from it.
- **"Blank" is measured, not judged by eye.** I take a 700 x 700 pixel sample of the map area each second for 30 seconds. Blank
  means 100% pure white for all 30 seconds; a drawn map is 0 to 1% white.
- **For the builds,** one dev server per build, each on its own clean worktree with no `.angular` cache, started **without
  `--poll`** (#2472), on `tamu-js-b159-nm`. That volume holds Angular 22.2.3, which matches the lock: `development`'s lock is
  unchanged since batch 159.

### So, plainly

1. **The map drawing blank is real.** The director's browser was right. It isn't every load, and it isn't every route: on a
   `?bldg=` load it drew every time.
2. **#2481 is what made it blank on every load:** applying `setSpriteSource` after the layer view exists. **Don't bring it back**
   as it is.
3. **#2477 is neutral**, the same as the control. It only routes the gallery's basemaps through `makeBaseLayer`, so it would bring
   the same one-in-four risk to those basemaps as well.
4. **Even #2466's way of applying it, on dev now, blanks about a quarter of plain loads.** With the override off, it never did. So
   it's `setSpriteSource` on a vector tile layer, whenever it lands relative to the layer view, that can leave the canvas blank. An
   apply that lands after the layer view exists does it every time.
5. **What's still unknown:** whether a real GPU blanks as often as SwiftShader. The maintainer's browser drew, and the director's
   didn't. Two different machines disagreeing fits an intermittent race better than a bug that always happens.

So the hatch is not recoverable as it is: the orange hatch and a reliable basemap haven't yet been shown together. **Nothing
pushed.**
