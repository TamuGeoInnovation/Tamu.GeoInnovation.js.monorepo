## The browser must treat it as secure

**Plain `http://gisday.local.test:4201` doesn't work.** auth0-spa-js needs `crypto.subtle`, which browsers give only to
https, `localhost` or `127.0.0.1`. The page stays blank (I looked: not even the header draws), and the console says "auth0-spa-js must run on a secure
origin". (`2026-11-16-107/plain-page1-no-login.png`)

**With "Insecure origins treated as secure"** set to that address (Playwright: full Chromium with
`--unsafely-treat-insecure-origin-as-secure`; the headless shell ignores it):
