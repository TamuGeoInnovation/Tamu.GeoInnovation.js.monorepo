## What it is

- **`test/e2e/gisday/admin-round-trip.ts`**, on the #3806 helper: `openAdmin` signs in, answers the API from fixtures
  (writes answered `{}`), and records every write with its body read as the API reads it, JSON or multipart, with
  repeated keys kept. `sentTo` waits for one.
- **`test/e2e/gisday/admin-round-trips.spec.ts`**: 18 tests, from g49's walk, area by area. Each Add test sends what
  was entered; each Edit test opens a made-up record with every field, checks the form shows them, changes one, and
  compares **the whole body sent**, not the one field:

| Area | Add | Edit |
| --- | --- | --- |
| RSVP Types, Submission Types | yes | yes |
| Sponsors | yes | yes |
| Affiliations (`/admin/organizations`) | yes | yes |
| Organizations (`/admin/places`), with links and visibility | yes | yes |
| Speakers, with a photo | yes | yes |
| Seasons, a day added (there is no Add page) | - | yes |
| The designer, each of Text, Dropdown, Radio and Checkbox | - | yes |
| Events: day, times, tags, speakers, location, broadcast | yes | yes, plus #3827 |

- **#3827:** `fix/3827-event-save-keeps-attendance` was **not on the fork** when I got there, so "An edit of the abstract
  leaves the recorded attendance alone" is `test.fail(true, '#3827: …')`. It accepts either fix: the counts left out of
