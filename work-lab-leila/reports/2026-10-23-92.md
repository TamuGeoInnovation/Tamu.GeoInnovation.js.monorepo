## 3. The upgrade

- **`got` `^11.8.5` → `~16.0.0`.** I chose 16.0.0 (30 August) because **16.1.0 was eleven days old**; `~` keeps the lock on 16.0.x. got 16 is
  ESM-only and needs Node 22 or later (we run 24.22.1).
- **One real change: got 12 and later send only the platform's `FormData`.** The first run of the helper's tests on 16 failed with
  *RequestError: Non-native FormData is not supported. Use globalThis.FormData instead.* So `HelperController` now:
  - builds its form with Node's `FormData`;
  - adds attachments as `Blob`s;
  - lets got set the multipart headers.

  The field-filter spec reads the native form's entries instead of `form-data`'s `getBuffer()`, with the same assertions. **`form-data` stays a
  dependency**: the Turnstile service still uses it, without got.
- **A type error only the build found:** `new Blob([file.buffer])` is *TS2322: Buffer is not assignable to BlobPart* (its memory may be a
  `SharedArrayBuffer`). The tests had passed, and the production build of the mailroom APIs failed. The buffer is now copied into a plain
  `Uint8Array`.
- **The other two calls needed no change**: `got.post(url, { json })`, `.json()`, `https.rejectUnauthorized`, the error types and the retry
  defaults (2 retries, never for POST) are the same in 16, and there is still no default timeout.
- **The lock**, by batch 41's method (`node_modules/got` removed and relocked), key by key: only got's own tree changes:
  - `got` 11.8.6 → 16.0.0; `cacheable-request` 7 → 13; `responselike` 2 → 4; `@sindresorhus/is` 4 → 8; `normalize-url` 6 → 8;
    `@types/http-cache-semantics` 4.0.4 → 4.2.0;
  - **`keyv` 4.5.4 → 5.6.0** at the top level, which lets the three nested `keyv` 5.6.0 copies (under `@cacheable/*` and `cacheable`) go;
    nothing else needs keyv 4;
  - added: got 16's own small dependencies (`byte-counter`, `chunk-data`, `tagged-tag`, `@sec-ant/readable-stream`, nested
    `decompress-response`, `lowercase-keys`, `mimic-response`, `type-fest`);
  - removed: got 11's (`@szmarczak/http-timer`, `cacheable-lookup`, `defer-to-connect`, `http2-wrapper`, `json-buffer`, `quick-lru`,
    `resolve-alpn`, three `@types/*`).
