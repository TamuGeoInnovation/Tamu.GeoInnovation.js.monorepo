## The design

- **Where it is stored:** four nullable `datetimeoffset` columns on the platform `Season` (`seasons`):
  `posterSubmissionsCloseAt`, `posterFilesCloseAt`, `presentationSubmissionsCloseAt` and `presentationFilesCloseAt`.
  - The platform season is where the submissions belong. The scoring window is on `vgi_seasons`, which belongs to the
    other (VGI) competition, so I followed its pattern but not its table.
  - `GET seasons/active` and `GET seasons/:guid` already return the new columns, so the site needed no new read
    endpoint.
  - A new season starts with no deadlines (open), because `incrementYear` copies only the year.
- **How the API enforces it:** each refusal is a **403 that says when the competition closed, in Central time**.
  - A new submission is refused once its competition has closed. It checks the season named in the body, or the
    active season if none is named.
  - A student's edit is refused once their competition has closed, or if the edit would move the submission into a
    closed one. Students can no longer move a submission to another season.
  - A student's file upload or removal (#2933) is refused once that competition's **file** deadline has passed.
  - Anyone with `update:competitions` is exempt, so reviewers and admins can still work after a deadline.
- **How an admin sets them:** a new `PATCH seasons/:guid/submission-deadlines`, which needs `update:competitions`. It
  refuses a value that isn't a date. It also refuses a file deadline at or before the submission deadline, since files
  must close later. Without a sign-in it answers 401 (checked).
- **The pages:**
  - Admin, Research Competitions: a new **Submission deadlines** section for the selected season. It has
    `tamu-gisc-date-time-picker`s with Clear buttons, as the scoring window does, and shows each time in Central
    beneath it.
  - The student form says when the chosen competition closes. After that, it says the competition has closed and
    when, offers no Submit or Update, and locks an existing submission.
  - The files panel says until when files can be attached, and stops taking them once that time has passed.
- **Shared, not copied:** the rules live in `libs/gisday/common/src/lib/submission-deadlines.ts`, used by both the
  API and the site. `inCentralTime` and `asDate` moved there from the VGI design form, which now imports them.
