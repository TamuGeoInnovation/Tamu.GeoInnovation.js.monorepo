## What looked wrong

1. **The default sign-off becomes a bullet point.** The profile template ends `- The Texas A&M GIS Day Team`, which
   Markdown turns into a one-item list. It's visible at the bottom of `after-email-html.png`. Every profile email sent with
   the default text would arrive like that.
2. **A bare link with `&` breaks.** `https://example.com/a?x=1&y=2` shows as `…x=1&amp;y=2`, and its `href` is
   double-escaped, so the link fails. `emailHtml` escapes `&` before `marked` runs. A named link, `[text](url)`, is fine.
3. **`[x](javascript:…)` isn't filtered in the email's HTML.** Angular neutralises it in the preview, but `emailHtml`
   passes `href="javascript:…"` into the email. Only admins write the text, so the risk is low.
4. **Placeholders are filled before rendering,** not after as #3044 asks. So a name with `*` or `_` would be formatted.
   The edit link is safe: 5,000 random tokens all stayed whole links.
5. **Minor:** `&copy;` shows literally, and `> quote` can't make a quote block.

**Escaping held in the preview:** `<script>`, `<b>` and `<img onerror>` typed into the text show as written, and none of
them ran.
