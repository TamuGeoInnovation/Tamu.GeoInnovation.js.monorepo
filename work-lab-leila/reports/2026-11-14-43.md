The public Sessions page now has a search box above the days. It finds a session by its name, building, room or a
presenter's name, and narrows the list alongside the Tags and Organizations filters.

Started 11:44 AM Central, reported 12:05 PM Central. No pull request was opened, and nothing was posted on GitHub.

## What changed

- **The API now sends presenters' names with each session.** `SimplifiedEvent` gained `presenters`, their full names.
  - **Why:** the day's events response dropped the speakers entirely, so the page had no presenter names to search.
  - **Only names go out.** A speaker's email and account are still removed, and a test checks it. These names are
    already public on the Presenters page.
- **The shared search helper, extended rather than copied:** `utils/search-text.ts` has a new `sessionSearchFields()`
  (name, building, room and presenters). The admin Events list now uses it too. It gets no presenter names there, so
  its search behaves as before.
- **The day card:**
  - It takes a `search` input and applies it together with the tags, organizations and the site's own place filter.
  - It reports how many sessions it shows (`matches`), and leaves the page while a search finds none of its sessions.
  - **Unchanged without a search:** a filter that matches nothing still says "No matching events for filter criteria."
  - It now combines its events and filters with `combineLatest` instead of `withLatestFrom`, because its template reads
    the list before the events arrive.
- **The Sessions page:** a `tamu-gisc-textbox` ("Search by name, building, room or presenter") above the days, and
  `No sessions match "…".` when no day finds anything. No new CSS.

**Where I looked for something to reuse:**
- `libs/ui-kits/ngx/forms`: `tamu-gisc-textbox`, used as it is.
- `libs/gisday/platform/ngx/common/.../utils/search-text.ts`: extended.
- The admin search (`tamu-gisc-admin-search`, `BaseAdminListComponent`): admin-only, so I followed their pattern
  rather than using them.
- The Presenters page (`people-view`, `presenters.ts`): its pattern is the one followed.
- `libs/gisday/common` and the global `styles.scss`: nothing was needed from them.
