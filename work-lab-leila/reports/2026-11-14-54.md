## The fix, behind the existing interfaces

Every `ControlValueAccessor` in the repository is in `libs/ui-kits/ngx/forms`. The commits are the tests (`7b32b099e`),
the resets removed (`cb4059987`) and the fix (`c07ddef6e`).
- **`AbstractValueAccessorFormComponent`** (textbox, range, turnstile, GIS Day place-link form): `writeValue` still sets
  `value`, so the range tooltip still updates, but the change and touch callbacks are skipped while the form writes.
- **Checkbox:** a written value is shown only. It isn't reported, isn't marked touched, and doesn't emit `changed`.
- **Checkbox group, select, date-time picker, file:** a written value is set directly, not through the reporting
  setter.
- **File:** `setDisabledState` used to put the disabled flag in as the file value and report it. It now leaves the
  value alone. The old spec that asserted this was rewritten.
- **Radio group and slide toggle** were already silent, and are unchanged.
- **Removed:** the `markAsPristine` after loading in the broadcast, class, venue, event, organization, place, speaker,
  sponsor, tag and university forms, and in the research competition review.
- **Kept:**
  - the reset after a review is saved;
  - the season form's own reset (#351);
  - #2942's `markAsDirty` calls for changes made by clicking.

## What depended on the old behaviour

Angular writes a form's first value before it registers the change callback. So the echo only fired for a value set
after the form was drawn, such as a record arriving later.
- **`(changed)` on checkboxes:** every binding (admin row selection, RSVP, my classes, trip planner, the sponsors list's
  Active column) uses `[checked]`, which never goes through `writeValue`. Unaffected.
- **`ngModel`:**
  - geoservices' mode toggle is a slide toggle, which never echoed;
  - the place-link form's inner textboxes only had the same text written back.
- **`valueChanges` subscribers** lose only a duplicate emission. The Nearmap date slider no longer runs an empty delayed
  step.
- **Values the echo used to rewrite** (a string to an array, `null` to `undefined`, a non-Date to `null`, the file's
  `false`): every caller already handles the unrewritten value.
- **Code that reads dirty or pristine:**
  - `BaseAdminDetailsPageComponent`: this is the fix.
  - `NewVersionService` (#2945): a page whose form was only loaded no longer blocks the reload after a deploy.
  - The geocoding Solve button (question 2).
