## What changed: the approach of PR 3014's dashboards (`c83ae4ae9`, on `development`)

- **Template:**
  - `columnMode` is `flex`;
  - each column's `flexGrow` equals its minimum, so none is squeezed below it;
  - `ngx-datatable` gets a `min-width` of the minimums' total.
- **Stylesheet:** `.datatable-container` gets `overflow-x: auto`.
- **The checkbox column is fixed at 56 px,** using `canAutoResize=false`. Flex mode ignores `maxWidth`, so this is the
  only way to stop it growing.
- **The minimums:**

  | Column | px |
  | --- | --- |
  | Name | 120 |
  | Submitted | 104 |
  | Submitted by | 130 |
  | Department | 110 |
  | Type | 112 |
  | Format | 100 |
  | Classification | 132 |
  | Final file | 100 |
  | Status | 136 |

  That's 1100 px in all, with the checkbox. They're set from the measured widths of the text: "Pending Review" in bold is
  110 px, "Presentation" 89 and "Undergraduate" 107. Classification also doesn't break inside a word.
- **Kept local:** a shared "sum of the minimums" helper and a shared scroll variant would change other tables
  (question 3).
