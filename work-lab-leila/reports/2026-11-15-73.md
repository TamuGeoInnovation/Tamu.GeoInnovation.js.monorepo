## #3050: the local site proxy sets `x-forwarded-host`

**What changed:**
- **What the API reads:** `siteHost()` reads `Origin`, then `x-forwarded-host`, then `Host`.
- **The script:** `gisday-local.sh` now reads the site's host from its `address` in `sites.ts`, and passes it to
  `gisday-site-proxy.js`.
- **The proxy:** it adds `x-forwarded-host` to every request it passes on. With no host given, it behaves as before.
- **The docs:** `docs/gisday-local.md` describes this, and its limit. A request that carries an `Origin` (POST, PATCH,
  DELETE) still names localhost, so it still answers as txgisday.org. That comes from reading the code; I didn't test a
  write live.
