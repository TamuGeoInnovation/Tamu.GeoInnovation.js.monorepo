## 2. Production keeps its allowance

**Production still prints placeholders.**
- **The evidence:** its run of the check passes only because, with its allowance, the spec asserts
  `toMatch(/___[A-Z_]+___/)` on a banner containing `Build Date:`. So the banner production prints has placeholders in
  it.
- **Why not the bundle:** I also read production's served `main-ALWI4YUM.js`, which holds `___CMS_API___` and

- **So:** the pipeline substitutes for dev and not, yet, for production. Production's allowance comes off once a
  substituting build is promoted, which means the next production release will fail this check until someone removes
  it. The pull request says so.
