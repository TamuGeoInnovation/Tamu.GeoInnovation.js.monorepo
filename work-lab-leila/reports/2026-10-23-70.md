**What GPLv3 means for a front end this repository serves, as plain facts and not a judgement:**
- AggieMap's built JavaScript, which bundles `lightgallery`, is distributed to every visitor's browser.
- GPLv3's conditions apply to distributing a work that includes GPL code: the whole combined work's source made available under GPLv3-compatible
  terms.
- This repository's source is public and MIT-licensed. MIT is generally regarded as GPLv3-compatible, but whether that settles it for this
  deployment is the maintainer's (or the university's) call, not mine.

**Is there a commercial licence?** **Nothing in the repository shows one:**
- no `licenseKey` in any `.ts`, `.html` or `.json` file;
- both uses call `lightGallery(element, {})`, with no options at all;
- **both versions complain when no key is given.** 2.9.0's code logs `console.error('Please provide a valid license key')`, and 3.0.0 logs
  *"lightGallery: please provide a valid license key"*. AggieMap's popups should log that today whenever a gallery opens;
- **3.0.0 also rejects older keys**: *"this license key is for v1 or v2 and is not valid for v3. Please upgrade to a v3 license"*. So even if a
  2.x commercial licence exists somewhere, upgrading to 3 would need a new one.

## 2. How AggieMap uses it

Two components, `libs/aggiemap/ngx/popups`: the **POI popup** and the **bonfire popup**.

- Each shows a **Swiper carousel** (`<swiper-container>`, one `<swiper-slide data-src="…">` per image).
- Each attaches `lightGallery` to that carousel, so clicking a slide opens it full screen.
- The stylesheet is `@import 'lightgallery/scss/lightgallery'` in `apps/aggiemap-angular/src/styles.scss`.
- The two components carry **the same code twice** (init, `onLightGalleryInit`, the swiper set-up). Under CLAUDE.md's reuse rule, any change
  here should become one shared piece.
