Save, Create, Delete and Submit Review on the GIS Day admin details pages now go back to the list the page was opened
from, as Escape does (#2942's `backToList()`).
- **The season** is in the list's address (`?season=…`).
- **The search** is in the list's history entry, not its address. It comes back with it.

## The change: one shared way

Commits: the tests (`387b0f9d4`), the change (`7e7f42a71`), the release note (`c90bb7e72`) and `.pr-body.md` (`b3ab433d4`).
- **New, in `libs/gisday/platform/ngx/common` (`modules/forms/admin-details-page.ts`, exported):**
  - an `AdminDetailsPage` token with `backToList()`;
  - `provideAdminDetailsPage(() => Page)`, which a page uses to provide itself;
  - `injectBackToList('/admin/<list>')`, which a form uses. On a details page it goes back through the page; anywhere
    else it falls back to the bare list, as before.
- **The 11 shared admin forms** (broadcast, class, event, venue, organization, place, season, speaker, sponsor, tag,
  university): `_navigateBack()` calls the helper, and their unused `Router` is gone. Their interfaces are unchanged.
- **`BaseAdminDetailsPageComponent`** implements `AdminDetailsPage`.
- **Each of the 23 subclass pages** gets one `providers:` line. Angular doesn't pass a base component's providers on to
  a subclass; this was checked in the installed Angular 22.2.4.
  - **A new spec, `every-page-provides-itself.spec.ts`,** fails if a page leaves the line out.
- **The Research Competitions review** saves in the page itself, so it calls `this.backToList()` directly.
- **"Leave without saving?"** is asked only by Escape. A save never triggers it, and the tests check that.

**Left as they were:**
- **Create Class, when some sections couldn't be added,** still stays on its page with them in the form.
- **Speaker edits** provides itself like the others, but has no save that leaves the page (question 2).
- **The user's own submission form** isn't an admin page.

**Where I looked for something to reuse:** `libs/ui-kits/ngx/**`, `libs/common/**` and
`libs/gisday/platform/ngx/common/**`, for back-to-list, navigate-back, go-back and return-to helpers. There was nothing
besides the base page's own `backToList()`, which this reuses.
