## 1. The helper and its signature

**It's in a new library,** `common-ngx-analytics` (`libs/common/ngx/analytics`, `@tamu-gisc/common/ngx/analytics`),
exported from its index.
- **Scaffolding:** copied from `common-ngx-local-store` (the same configs and lint rules), plus a README.
- **Strictness:** `strictNullChecks` is on from the start.

```ts
trackEvent(analytics: Pick<Angulartics2, 'eventTrack'>, action: string, category: string, custom: Record<string, unknown> = {}): void
stampedEvent(custom = {}): { guid: string; date: number } & Record<string, unknown>   // guid, then date, then custom
```

**Why this shape:**
- **Positional `action, category`:** every call site reads as one line, in the order `eventTrack.next` nests them, for
  example `trackEvent(this.analytics, 'routing', 'feedback', label)`.
- **The page's own `Angulartics2`:** every site already injects one, so no component's injection changes. An injectable
  `AnalyticsService` would have meant a provider change in each of the 13 files.
- **`stampedEvent` is exported too,** so the payload can be asserted on its own, and built for any future sender.

## 2. The payload shape, kept byte-for-byte

**Each site keeps its own `label` object,** minus its first two lines (`guid`, `date`), and any code that adds
`stop_N` fields after it.
- **What the helper does:** it puts `guid` and `date` first and spreads the label after them. So every `gstCustom` has
  the same keys, in the same order, with the same values.
- **The notification containers** keep their `analytics !== null` guard.

**Not changed, on purpose (Q-a29-1):**
- **The trip planner's travel-options event** has always sent `{ type, date, guid, ...opts }`: `type` first, and
  `date` before `guid`. Routing it through the helper would reorder its keys. It keeps its hand-built object, with a
  comment saying why.
- **The 8 unstamped events:**
  - the basemap gallery (`gstCustom: event.basemap.id`);
  - the Nearmap slider;
  - the GIS Day submission form;
  - the event maps' builder steps (intro, accommodations, review ×2) and its settings guard.

  Giving them a stamp would change their payload, which the batch rules out.
