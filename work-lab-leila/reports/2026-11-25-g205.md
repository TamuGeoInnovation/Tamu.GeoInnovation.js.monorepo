declares them `Date`.
- **What I did:** the fixture uses `Date`s now, as the type says. The component reads either through `asDate`, so the
  tests pass unchanged.
- **The gap:** the type isn't what arrives over the wire.

The options:
- **(a)** Leave it.
- **(b)** File an issue (Low) for a wire type, with dates as `string`, for the Angular side.

**I recommend (a)** unless a bug turns up: `asDate` already absorbs the difference.
