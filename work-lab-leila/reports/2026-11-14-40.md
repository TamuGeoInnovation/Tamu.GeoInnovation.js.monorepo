✘ [ERROR] TS2349: This expression is not callable.
  Each member of the union type '{ (observerOrNext?: Partial<Observer<{ rejected: boolean; }>> | ...): Subscription; ... } | { ...; }'
  has signatures, but none of those signatures are compatible with each other.
    speaker-edits.component.ts:58:54

**The likely cause**, from reading the code (not changed or tested here): in `decide()`,

```ts
const request = decision === 'approve' ? this.edits.approve(edit.guid) : this.edits.reject(edit.guid);
```

`approve` and `reject` (in `speaker-edits.service.ts`) return Observables of different types,
`{ approved: boolean }` and `{ rejected: boolean }`, so `request` is
a union of two Observable types, and TypeScript can't call `.pipe` or `.subscribe` on that union. Giving `request` one
type, for example `const request: Observable<unknown> = ...`, should be enough, as `next` ignores the value.

**Why home's tests didn't catch it:** `gisday-platform-ngx-core:test` passed here too. Only the production build
typechecks this file, which is CLAUDE.md's "build to typecheck, don't rely on tests".
