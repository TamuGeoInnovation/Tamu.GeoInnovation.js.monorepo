## What changed: only the shared dashboard table

Everything is in `libs/gisday/platform/ngx/core/.../dashboards/shared/dashboard-table/`. RSVPs and Check-ins both get it,
and neither page component changed.

- **Smaller minimum widths,** set once in `DASHBOARD_TABLE_WIDTHS`:

  | Column | Before | Now |
  | --- | --- | --- |
  | Name | 200 | 192 |
  | When | 110 | 88 |
  | Total | 56 | 66 |
  | Count | 88 | 75 |

  Check-ins' ten columns now add up to 871 px, inside the 879 px the page gives the table. Before, they added up to 982.
- **Each column's `flexGrow` now equals its minimum.** With the old ratios, ngx-datatable's flex mode didn't give back
  the width a column pinned at its minimum took, so even an exactly-sized table came out too wide.
- **`ngx-datatable` gets a `min-width` of the minimums' total.** When there's less room, the existing `.dashboard-table {
  overflow-x: auto }` box scrolls, instead of ngx-datatable cutting columns off.
- **Count and total cells have 0.25rem side padding (was 0.5rem),** in the table's existing stylesheet. With that,
  "academia" (66 px) and "Checked" (58 px) fit their columns.
- **What was reused:** the scroll box, the column classes and `libs/sass/components/_datatable.scss`. The shared spacing
  utilities can't reach ngx-datatable's cells. No new component or stylesheet.
