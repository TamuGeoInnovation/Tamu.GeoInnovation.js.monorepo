## 1. One shared result

**On `TripPlannerService`:**

```ts
public readonly currentResult$: Observable<TripResult> = this.TravelOptions.pipe(
  switchMap(() => this.getTripResultForTravelMode()),
  shareReplay({ bufferSize: 1, refCount: true })
);
```

- **Once per change:** it's fetched and drawn once per change to the travel options or the results, however many
  components subscribe.
- **`refCount: true`:** it draws only while at least one component is subscribed, as the five did.
- **Late subscribers** get the current result without drawing it again.
- **The interface:** `getTripResultForTravelMode()` is unchanged and public, for anything else that calls it.

**The five components** now read `this.<service>.currentResult$.pipe(takeUntil(this._destroy$))`.
