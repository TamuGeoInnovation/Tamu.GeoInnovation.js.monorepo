# ui-kits-ngx-qr-code

A QR code drawn from text, such as a link. Optionally, buttons that download it as a PNG to put on a slide
or a poster (`downloadName`), and that fill the screen with it, with a caption, for a presenter sharing
their screen (`fullscreen`, `caption`). First used for GIS Day's check-in by QR code (#2560).

Run `nx test ui-kits-ngx-qr-code` to execute the unit tests.
