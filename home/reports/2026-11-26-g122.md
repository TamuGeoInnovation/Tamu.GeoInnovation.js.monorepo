would have kept almost everything. Before the maintainer's commands, that was 425 of the 452 branches. So a branch was

1. its tip was in `origin/development`;
2. a remote branch contains it;
3. merging it into `origin/development` changes nothing (`git merge-tree`). That test can wrongly keep a branch, never
   wrongly delete one;
4. its pull request merged and it has **no commit dated after the merge**, so nothing was added after the squash.
