## What was built

1. **The probe's `serviceName`.** This is `sourceJSON.name`, read only once the layer has loaded. It is `null` for
   a layer that did not load, or that has nothing behind it (GeoJSON, graphics, groups). The probe also has
   `basemap`, explained below.
2. **`test/smoke/aggiemap/layer-title-overrides.json`.** It lists map, layer id, title and reason. `map` is the
   event map's id, or `main` for the layers every map loads. Its unit spec, `layer-title-overrides.spec.ts` in
   `ts-events-ngx`, reads the event definitions and the main map's `LayerSources`. It fails:
   - a title with no entry;
   - an entry whose title differs from the definition's;
   - a stale entry;
   - an entry with no reason.
3. **The smoke check, in `maps.spec.ts`.** It uses the snapshot that test already takes, so no second crawl. Each
   layer gets one verdict:
   - `service`;
   - `declared`;
   - `declared, same as service`, meaning the override could come off;
   - `declared, not shown`, which **fails**;
   - `wrong`, which **fails**;
   - `did not load`, whose name is **not judged**;
   - `no service` and `basemap`, which are not judged.

   Every map's verdicts go in a `layer titles` annotation. The assertion is soft, and skipped on builds
   without `serviceName`.

**Red then green.** The probe spec failed on the unmodified probe. The override spec failed with one entry
(`construction_zone-layer`) removed from the list. Both pass with the change.
