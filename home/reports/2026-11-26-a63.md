## What this changes

Moves the eight Nx packages from **24.0.6 to 24.0.7**, together, since they pin each other: `nx`, `@nx/angular`,
`@nx/eslint`, `@nx/eslint-plugin`, `@nx/js`, `@nx/vitest`, `@nx/webpack` and `@nx/workspace`. It is a patch.

**This is a deliberate exception to the seven-day rule.** `nx` 24.0.7 was published on 25 November 2026, one day before
this, where CLAUDE.md asks every release to be eight days old. The maintainer decided to take it now, and the decision is
recorded on #3738.

**Why it can't wait: it is the gate for the Angular chain.**
- Angular 22.3.0 (PR 3724) brings `@angular-devkit/architect` 0.2203.0. Its new `exports` map allows
  `@angular-devkit/architect/node` but not `@angular-devkit/architect/node/index.js`.
- Nx 24.0.6's `nx/dist/src/adapter/ngcli-adapter.js` imports the second, at line 941, so with Angular 22.3 every
  Angular application's production build fails.
- Nx 24.0.7 imports `@angular-devkit/architect/node`.
- PR 3724 is rebased onto this once it merges. No `@angular/*` package moves here.

**What the lock moves:**
- only the Nx family: the eight, `@nx/devkit`, Nx's native binaries, and a new `@isaacs/nonrecursive-glob-match` 1.1.0
  that Nx 24.0.7 depends on, nested under `nx`;
- plus same-version moves within the tree (`picomatch`, `find-up`, `parse5`, `@types/yargs`).

The lock goes from 1,654 to 1,645 packages. No package outside the eight resolves anything new, apart from
`@nx/devkit` taking `nx` 24.0.7. npm's regeneration also floated `ci-info` from 4.4.0 to 4.5.0, which only `jest-util`
uses. That was put back, and npm keeps 4.4.0.

`nx` 24.0.7 peers `typescript ^5.8.0 || ^6.0.0`, so like Angular's `>=6.0 <6.1` it holds TypeScript below 7 (#1918).
