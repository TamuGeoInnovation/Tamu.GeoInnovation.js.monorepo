## What it is
- **`test/smoke/aggiemap/map-layers.spec.ts`**: one test per map, 70 on production: `<route> lists, draws and keys every layer it shows`.
  Waits for `probe.ready`, `drawing === false` and an `arcgis-map`; a map that does not settle in 240 s, or has no layers,
  **fails with the probe's state in the message**, so a wrong route cannot pass as empty.
  1. **Listed**: every layer the definition declares is in the Layers list (found by id on the map, then by the title it ended
     up with). The main map, which has no definition, requires every top-level non-hidden layer in the view to be listed.
  2. **Drawn**: a layer holding features in the extent must have **at least one** that its own renderer gives a symbol
     (`getSymbolAsync`, paged up to 2,000). A layer that is off is asked through its service for the same extent, which is how
     the main map's hidden layers are covered. The share without a symbol is recorded as an annotation.
  3. **Keyed**: every layer shown on in the Layers list has a legend collection with a row holding an `img`, `canvas`, `svg` or
     background image (matched by title, or by row label where untitled). Excluded: `legendEnabled: false`, layers that failed
     to load, services with 0 features, allowed failures; Safety First by name, with the reason (the legend shows it as a message).
- **Declared layers: `declared-layers.generated.json`** (204 ids, keyed by map), written by a Vitest spec in `ts-events-ngx`
  (`declared-layers.spec.ts`) through `toMatchFileSnapshot`: it can import the definitions, which Playwright cannot. CI's
  `nx test ts-events-ngx` fails when it goes stale, and `-u` rewrites it. The crawled `map-manifest.generated.json` could not be
  extended: it is built from the deployed site and cannot know what a map should have.
  Declared means: sources in the map's `references` with `listMode` not `hide`, minus layers a builder choice hides or relists;
  `hideLayerToggle`/`hideSidebar` maps (three campus maps, the dining kiosk) list nothing. Four maps declare nothing checkable
  (every layer depends on a choice); 12 builder-gated maps skip, naming `tools/builder-inventory`.
- Not `@heavy` (one load per map, as `maps.spec.ts`); added to `scope.ts`'s `ROUTE_SPECS`, so quick runs core and changed routes
  and release runs every map. `docs/testing.md` row added (70; total 480 to 550). About 10-11 minutes for 70 maps on 6 workers.
- The work machine's scan never reached the mailbox, so the legend check was written here to your rules. At 1280 px the main
  map renders its Layers list on load (10 items); "behind the menu" is probably a narrower window.
