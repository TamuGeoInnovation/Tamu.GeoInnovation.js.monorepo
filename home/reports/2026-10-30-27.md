## What changed

- **`EventConfiguration.gameDayRefresh?: { enabled: boolean; layers: string[] }`**
  (`interfaces/special-event.interface.ts`), documented beside the field:
  - `layers` names each layer that polls;
  - `enabled: false` keeps the list ready for when the owner wants it on;
  - one minute, fixed. No caller needs another value, so it is not a setting.
- **Applied in one place: `EventSettingsService.eventLayerSources`**, which every event layer is drawn from (the event
  service and the sidebar both read it). A private `gameDayRefreshed`:
  - copies only the sources it changes, adding `refreshInterval: 1` beside their existing `native` settings;
  - returns every other source as the same object;
  - leaves the definition itself unmutated.
- **Football**, in `FootballParkingConfiguration`: on, with `layers: [...VEHICLE_MODES.map((mode) => mode.layers.lots),
  FP_RV_PARKING_LOTS]`. That is the five lots layers and nothing else. `lotsNative()` no longer sets `refreshInterval`.
- **Men's Basketball**: on, all three layers (`GATES`, `SYMBOLS`, `PARKING_LOTS`). **Its local `gameDayNative()` is
  deleted**; the three layers' `native` is `{ outFields: ['*'] }`.
- **Women's Basketball**: **off**, both layers listed.
  - The comment records that Megan, who asked for the men's refresh, asked on 30 October that this map not refresh
    (#2581).
  - **Her reason was not in the relay, the issue or the batch**, so the comment says so and says to ask her before
    switching it on. I did not invent one; see question 1.
- **No layer definition sets `refreshInterval` any more**: `grep` finds it only in the settings service. That makes
  this one mechanism, not a fourth alongside the old three.

### The helper parameter from batch 26: dropped

The switch lives on the event, so the optional `refreshInterval` on `athleticsDevelopmentSource` would be a second way to
do the same thing. It isn't in this branch.
- **Its two strict guards are kept** (`definitions/common.definitions.spec.ts`). They hold the helper's output to
  exactly the source each caller gets today, with no key added.
- **The same idea now guards the new shape**: every map without the switch on is served the very source objects its
  definition declares (identity, not just equality).

`chore/2581-athletics-refresh-option` is superseded. Delete it from the fork when convenient.
