## #3032 and #3033: one "sessions that use this" list

- **`SessionsUsingComponent`** in `libs/gisday/platform/ngx/common/src/lib/modules/sessions-using/`, exported from the
  index. It takes the sessions and its wording, keeps the site's own (`siteListsSession`), sorts by `sessionTime`, and
  draws them in the admin Events list's `floating-table` (no new CSS), each name linking to `/admin/events/edit/<guid>`.
- **Routes:** `GET event-broadcasts/:guid/sessions` behind **`update:event-broadcasts`**, and `GET tags/:guid/sessions`
  behind **`update:tags`**. Both permissions are ones admins already use on those entities, so nothing new is needed in
  Auth0. They're admin-only because they list sessions hidden from the public schedule.

## #3034: Only sessions with no tags

The admin Events list **has no tag filter**, contrary to the issue's assumption. So "No tags" is a checkbox through the
filter it does have (`listFilters`/`keepEntity`, as the organizations switch is): kept when coming back from a session,
and the list shrinks as sessions are tagged. The season's events route now joins `event.tags`. That route is public, but
tags already show on the public Sessions page.
