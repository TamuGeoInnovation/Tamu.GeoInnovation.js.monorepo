## Which option: the first, one component

The event sidebar differed from the main map's in only two ways: a tab filter (`sidebarTabs`, for satellite
campuses) and a campus branding image. Both are options, not grounds for a second component, so:

| Piece | What it is |
| --- | --- |
| `SIDEBAR_TABS` (`aggiemap-ngx-ui-desktop`, `sidebar-tabs.ts`) | The tabs, declared once, in order, with their reasons; Experiments is `developmentOnly` |
| `AggiemapSidebarComponent` | Draws them; now the side panel of **every** map. `MoveInOutSidebarComponent` is deleted |
| `sidebarRoutes(reference)` | The panels behind the tabs, the same for every map; only the landing panel differs |
| `SIDEBAR_OPTIONS` | How a map changes its panel; the event maps provide it from their definition |
| `sidebarTabs?: SidebarTabId[]` | Derived from the declaration, so it can name every tab |

**The drift was in the routes too, not only the templates.** The event maps had no `bus` or `experiments` panel,
so adding the tabs to their template alone would have given two tabs that opened nothing. And **their trip planner
Options page was never gated** when #2801 gated the main map's, so on production
`/events/tailgating/map/d/trip/options` still opens. `sidebarRoutes` carries the gate, and `DEVELOPMENT_ONLY_PAGES` now
names that address, red on production first.

**What can still drift:** nothing in the desktop panel. Two things outside it, as questions below.

**One correction to the batch:** Bus Routes is not development-only. It has been on every environment since #2789
(9 November), and `SECTIONS_ON_EVERY_ENVIRONMENT` already says so. Only Experiments is gated.
