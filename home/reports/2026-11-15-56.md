## What it does

- **One shared piece:** `LinkedSearchComponent` in `libs/gisday/platform/ngx/common/src/lib/modules/search/linked-search/`,
  exported from the library's index. It has the textbox, the address following it as `?search=` (debounced, replacing
  the history entry, **merged** so Sessions' `tags`/`orgs` stay) and **Copy link** inside the box. The page passes its
  own control and keeps its own matching. **Presenters** now uses it, and its own copy of the code is gone. **Sessions**
  uses it in place of its plain textbox.
- **`searchFromAddress(route)`** beside it: a page's control starts from the carried `?search=`. My first version set it
  from inside the box, and the check caught Angular's NG0100 on Presenters (its list changed mid-check). It's fixed by
  reading it when the page is made; Sessions' signal starts from it too.
