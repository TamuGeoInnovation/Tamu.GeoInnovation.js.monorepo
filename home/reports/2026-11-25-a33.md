## 3. One pair, in `aggiemap/ngx/popups`

- **`MarkdownPopupComponent`** now extends `BaseDirectionsComponent`:
  - title from `name`, falling back to the layer title;
  - a description section only when there is a non-blank description;
  - a copy field when there is a link.
- **`MarkdownWDirectionsPopupComponent`** extends it and adds the footer in its own section, as the building popup has
  it.
- **The event maps' link comes in through an injection token, `POPUP_SHARE_URL`**, exported from the library's index.
  - AggieMap's components cannot import the event maps, because the events library imports AggieMap's. So the "share-URL
    behaviour from the overridable base" is reached this way: the markdown popups override `_makeShareUrl` to use the
    token when provided, and fall back to the base's otherwise.
  - The event maps provide it from the map route (`ts-events.routes.ts`, beside `EventSettingsQuery`). AggieMap provides
    nothing, so its markdown popups still show no link.
  - Only the markdown popups read the token, so every other popup's link is unchanged. Dining, Building and Construction
    are also used on event maps, and they are not affected.
- **The event maps' share-link code** moved out of `BaseEventPopupComponent` into `event-share-url.ts`, unchanged in
  behaviour. The provider and the campus building popup, the one component still extending that base, call the same
  function.
- **The event maps' two markdown folders are deleted.**
  - `EventPopups.Markdown*` now point at `Popups.Markdown*`, so none of the roughly 150 definition references changed.
  - The campus building popup took its stylesheet from the deleted folder, so it now has its own: the same two imports.
