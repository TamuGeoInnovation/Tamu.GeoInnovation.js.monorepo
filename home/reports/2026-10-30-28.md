## The check: inverted, as you recommended

`test/smoke/aggiemap/map-layers.spec.ts`, check 2a.

- **What it does.** For **every** layer with a definition expression, the in-browser walk asks the service two
  counts: `1=1`, then the filter. A filter that selects none of a non-empty layer fails the map. The annotation
  records `filter="..." selects n/m` for each layer, pass or fail.
- **Exempt by form** (`emptyByDesign`):
  - `1=0`, which hides a layer for a choice not made;
  - a `DATE '...'` window, which selects nothing outside its event.

  These need no list and cannot go stale.
- **Exempt by name.** `allowedEmptyFilters` in `environments.json` lists the rest per environment, by map path and
  then layer, each with its issue. It is read with the same helper as `allowedMapLayerFailures`, which is now
  `perMapEntries(key)`.
  - A listed layer is reported as a known failure.
  - Once it selects features again, it is reported as "known failure passes; remove it". That follows the
    repository's pattern.
