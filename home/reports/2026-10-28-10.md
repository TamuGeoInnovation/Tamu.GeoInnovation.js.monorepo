## The change

- **The tiles' outline is hidden with the fill.** `hiddenStyleLayers` now lists `Campus Structures/Currently Under
  Construction/1` (the pink `fill-pattern`) and `.../0` (the black `line`, 1.33 px). No code change was needed: the list takes
  any style layer.
- **The outline is ours.** The construction symbol's first symbol layer is a `CIMSolidStroke`, black, 1 pt (= 1.33 px, as the
  style drew it), followed by the two `CIMHatchFill`s. CIM draws the first symbol layer on top, so the edge runs unbroken over
  the grid. The comments in the definition say why the outline had to move: a layer added to a vector tile basemap can only draw
  above the whole of it.
- The hatch callback is now typed `__esri.CIMHatchFill`. Without that, TypeScript widened the stroke colour to `number[]`, which
  Esri's `CIMColor` (a 4-tuple) refuses; the build caught it.
- **Unchanged from batch 9:** the sprite override stays deleted; the tests, the release note and its #2506 caveat are all still
  there.
