## My judgement: 60% holds up, at 16 too

- **The label:**
  - At zoom 18, before, a solid grid line falls between the 5 and the 2, so the label reads *15 24*. After, the lines are a pale
    orange and the digits read as one number. A faint line still crosses it, but it no longer splits the number.

  orange on grass, and the building is as identifiable as before.
  - **The black outline does most of that work**, and it is unchanged.
  - At Fort Worth's zoom 16 the four sites still stand out.
- **I wouldn't go to 75%.** On the evidence, 60% fixes the label without costing the building at 16. That call is the maintainer's, and
  the zoom 16 pair is the one to look at.

## Findings

- **The construction service intermittently fails feature queries at zoom 17 and 18 in College Station**, so 1524's grid is sometimes
  only part-drawn: several "Unable to complete operation" responses a minute, on both builds. A visitor would see a half-hatched
  building now and then. This is not filed; it may be the service's load at the time. If it recurs, it deserves an issue for the GIS
  team, with the query URLs.
- **For anyone scripting the map:** `view.goTo({ target: { type: 'point', ... } })` with a plain object applies the scale but leaves the
  centre where it is in this API version. Pass a real `Point`, for example `view.center.clone()` with x and y set.
