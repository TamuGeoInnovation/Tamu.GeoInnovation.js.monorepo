## Choice: name first in the markup (your second option)

The name is now first in the DOM on both pages; `flex-direction: column-reverse` keeps it below the picture on desktop and `column` puts it above on a phone (max-width 768px). Reasons: the name is what is being chosen, so it is read first by everyone; the reading order no longer changes with breakpoint; and `column-reverse` on a phone would have left a screen reader hearing the picture first. On `/all-maps` the tile's `aria-label` ("Open the X map") already overrides the content, so the order only matters visually there; on `/all-maps/campus` the link's name is built from its content, so a reader hears the name and then the alt ("X map"), so the name is said twice either way. I left the alt alone (making the picture decorative would be a separate, small accessibility change; say if you want it).

`map-columns.component.html`: a pictured entry is now `label, img`; a glyph entry is still `icon, label` (the markup branches on `app.thumbnail`). `all-maps.component.html`: `label, img`.
