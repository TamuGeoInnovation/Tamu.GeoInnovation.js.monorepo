## Things to know

- An opaque PNG upload can now be stored as JPEG bytes under its `.png` name. Browsers sniff `<img>` content, so it displays; anything that trusts the extension or stored MIME would see a PNG. I did not change `saveAsset`.
- **Cannot be avoided:** a scaled PNG **with transparency** can still be larger than the upload (the test image went to 771,631 bytes), because only PNG keeps the alpha channel. A too-large image is always scaled, so the original cannot be kept. The same holds for an opaque image where even JPEG q80 is larger than the original (a high-contrast synthetic pattern did that).
- I replaced the old test `keeps a PNG a PNG`, which used an opaque PNG, with a transparency variant, since an opaque PNG may now become a JPEG.
