## How each fits what we run

Today: `lint.yml` is a reusable workflow called with a base ref on pull requests (checkout, Node 24.22.1, `npm ci`, lint). `security-scan.yml`
runs daily at 06:42 College Station time with `contents: read, issues: write, packages: read`, runs `npm audit` and Trivy, and
`tools/security-findings/check.mjs` compares the result with `.github/security/accepted-advisories.json` to open or close one
`security-health` issue. The directory also has `install-scripts.mjs`, so some install-script checking exists.

- **OSV-Scanner:** add a job that runs `osv-scanner scan --lockfile package-lock.json --format json`, filters to `MAL-` ids and feeds
  `check.mjs`'s existing accepted-list comparison. It adds no new secret and no new App. It could also use the pull-request workflow
  for a check, but a pull request that changes the lock is the case it covers least well, because a freshly published bad version may
  not be in the feed yet. Needs `contents: read` only (plus `security-events: write` if SARIF is used).
- **Socket:** nothing to add to `lint.yml`; the App comments by itself. It is the only option here that judges a package by its
  behaviour on the day a pull request adds it.
- **Safe Chain:** would wrap `npm ci` inside `lint.yml`. Its 48-hour rule overlaps our 14-day rule (#2292), so it adds nothing to
  version choice, and it has no pull-request surface.
- **Phylum, Aikido's platform:** paid, so no.

## Recommendation: OSV-Scanner for malicious-package records, in the daily scan, now; consider Socket's free App as a second step

1. **OSV-Scanner in `security-scan.yml`** (and optionally in the pull-request path): free, no App or token, reads our lock, fits the
   existing accepted-list design. Its limit: it detects only what has been reported, after publication. It is not behaviour analysis.
2. **If the director wants behaviour analysis on pull requests**, install **Socket's free GitHub App**. It is the only free option that
   inspects what a new or changed package does. Its costs are a third party's App with read access to this repository and a risk of
   comment noise; the maintainer should decide that, since it is an organisation setting (admin only).
3. Skip Aikido's platform and Phylum: they cost money, and a public repository has no budget for them.
